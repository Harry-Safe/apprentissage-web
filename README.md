# Apprendre à développer

Projet personnel de Franck, débutant en programmation.

## Objectif

Apprendre à comprendre, écrire, modifier et dépanner de petites applications web. Le fil conducteur sera un carnet personnel de projets : une page, puis une liste interactive, puis une sauvegarde locale.

Ma classe poursuit son développement dans son propre projet avec Codex et Claude. Son évolution ne dépend pas de ces exercices. Les notions apprises pourront aider à en comprendre progressivement le fonctionnement.

## Méthode

- Une notion et un petit exercice à la fois, avec des séances indicatives de 15 à 30 minutes, sans calendrier imposé.
- Franck réalise la modification et décrit ce qu'il observe.
- L'assistant explique, donne des indices, relit et aide à comprendre les erreurs.
- Une étape est acquise lorsque Franck peut expliquer son changement et le refaire avec une petite variante.
- L'assistant ne marque pas un exercice terminé simplement parce qu'il a fourni les fichiers.

## Parcours indicatif

1. HTML : titres, paragraphes, liens et structure d'une page.
2. CSS : couleurs, espaces et mise en page.
3. JavaScript : boutons, variables et conditions.
4. Listes et objets : gérer plusieurs entrées du carnet.
5. Sauvegarde locale : retrouver les entrées après fermeture.
6. Dépannage et vérifications : comprendre une erreur et contrôler une fonction.
7. Git et GitHub : conserver une modification, lire son historique et revenir à une version précédente.

Le parcours s'adapte aux progrès observés. GitHub pourra être introduit tôt pour conserver les premières étapes, en expliquant chaque action.
