# Séance 1 — Modifier sa première page

But : constater comment une modification de texte dans un fichier change une page affichée.

## Une notion

HTML décrit le contenu d'une page. Une balise est un repère écrit entre les signes `<` et `>`.

Exemple :

```html
<h1>Mon atelier</h1>
```

`<h1>` ouvre le titre principal ; `</h1>` le ferme. Le texte au milieu est celui affiché dans la page.

## Ton exercice

1. Ouvre le fichier index.html dans un navigateur pour voir la page de départ.
2. Ouvre le même fichier dans un éditeur de code ou de texte brut. Si tu ne sais pas quel outil utiliser, commence par le dire à ton assistant : ce sera la première manipulation guidée. Évite Word et le mode texte enrichi de TextEdit.
3. Repère la ligne `<h1>Mon atelier</h1>`.
4. Remplace seulement `Mon atelier` par un titre de ton choix. Garde les balises autour.
5. Enregistre le fichier, puis actualise la page dans le navigateur.

Observe ce qui a changé. Le titre de l'onglet a-t-il changé aussi ?

## Pour reprendre ensemble

Décris ce que tu as fait et ce que tu vois, ou copie la ligne modifiée dans le chat. Inutile de comprendre tout le fichier aujourd'hui.

L'exercice reste à faire : l'assistant a préparé le point de départ, pas réalisé ta modification.
